# 🚀 AvyyTheTechSavyy — Personal Blogging Platform

A clean, minimal, **Medium-inspired personal blogging platform** built with React.js, designed for developers to write, manage, and showcase their thoughts, learnings, and projects.

This project focuses on **content-first design**, smooth user experience, and a structured frontend architecture — making it both a **personal tool** and a **portfolio-grade project**.

---

## 📌 Features

* ✍️ **Write Blog Posts (Markdown Ready)**
  Create and format posts for sharing knowledge and ideas.

* 📄 **View All Posts**
  Clean, centered feed inspired by Medium for distraction-free reading.

* 📝 **Edit Posts**
  Update content anytime with a seamless editing experience.

* ❌ **Delete Posts**
  Remove posts instantly with UI-based controls.

* 📖 **Dedicated Post Page**
  Read full articles with optimized typography and layout.

* 🧠 **"Today I’m Building" Section**
  Share daily progress, ideas, and development logs.

* 💡 **Upcoming Ideas Panel**
  Maintain a list of future blog topics.

* 💬 **Feedback Box**
  Allow users to suggest improvements or topics (peer review ready).

---

## 🧠 Objective

This project is designed to:

* Build a **real, usable personal platform** instead of a generic CRUD app

## 🎨 Design Philosophy

## 🧪 Core Functionality Flow

1. User writes a post → saves content
2. Post gets stored in local state
3. Feed displays all posts
4. User can:

   * Edit → updates state
   * Delete → removes post
5. Clicking a post → opens full article view
